## Why these 11

Picked for running Rafa's account. Each maps to a standing workflow in
`docs/workflows.md`:

| Skill | Rafa workflow |
|---|---|
| `social` | Content planning, reels, engagement, listening |
| `content-strategy` | Pillar planning, calendar, repurposing |
| `copywriting` | Captions, hooks, scripts in Rafa's voice |
| `copy-editing` | Final pass on every caption before posting |
| `image` | Briefing image generations, art direction |
| `video` | Reel concepts, scripts, shot structure |
| `analytics` | Reading insights, what to double down on |
| `ab-testing` | Posting-time experiment (9am/1pm/7pm ET) and caption tests |
| `marketing-loops` | Growth loops: follows → saves → shares |
| `product-marketing` | Positioning Rafa: "100% digital, 100% real talk" |
| `customer-research` | Understanding the audience as it grows |

**Later, when relevant:** `ads`, `ad-creative`, `attribution`,
`influencer-marketing` (paid promotion / partnerships).
